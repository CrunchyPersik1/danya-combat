# 🥊 Даня Комбат

Браузерная игра-кликер про Даню: прокачка, магазин, ящики, пассивный фарм с музыкой из скинов,
PvP-арена с комбо-приёмами и трейд-система с живыми курсами.

**Стек:** Vite + React + TypeScript. Сборка — полностью статическая, готова для GitHub Pages.

---

## 🚀 Быстрый старт

    npm install
    npm run dev        # дев-сервер
    npm run build      # прод-сборка в dist/
    npm run preview    # локальный просмотр сборки

## 🎮 Что внутри

### Основная механика
- Большая иконка Дани в центре. Клик: scale-анимация, glow, вспышка, волна, частицы, RGB-фон.
- За клик начисляются **ДэнКоины**. 7% шанс крита (x6), 20% шанс выпадения рублей.
- XP и уровни: уровень даёт +5% ко всему доходу.

### Валюты
| Валюта | Где взять | Зачем |
|---|---|---|
| 💰 ДэнКоин | клики, автофарм, ящики, PvP, ивент | скины, обмен, ящики |
| ₽ Рубли | клики (20%), ящики, PvP, промокоды, трейд | улучшения, трейд |
| 💎 Алмазы | Шахта алмазов | ящики (+0.2% дохода за штуку) |
| 🏅 Золото | Наивысший гриндер золота, супер-боксы | супер-боксы (+1% дохода) |

### Магазин
Улучшения: Множитель нажатий (x1 → x10000), Сигма Майнер 1.0, Сигма Майнер 10к, Шахта алмазов,
Наивысший гриндер золота (+25% ко всему доходу за уровень). Покупка пачками x1/x5/x10/x25.

Скины: Даня, Ресоурс, Веном (8000), Золотой Денчик, Ночной Даня + Кибер/Алмазный/Сигма/Демон (только из ящиков).
Каждый скин даёт множитель клика и пассивный доход.

### Ящики
- **Дэн Бокс** — 5000 ДэнКоинов или 15 алмазов.
- **Супер Бокс** — 75 000 ДэнКоинов, 120 алмазов или 250 золота: легендарные скины.

### Пассивный фарм ивент
Все купленные скины выходят на сцену и играют каждый свою ноту в своём ритме (Web Audio API) —
вместе получается трек. Доход: **V (деньги в день) × T (время)**, 1 игровой день = 10 секунд.
Комбо скинов даёт +15% за каждого следующего. Тап по скину — бонус.

### PvP Арена
10 противников («Злые Дани») с AI: атакуют, блокируют, лечатся.
- Атаки: лёгкая (A), тяжёлая (S), СПЕЦ за 40 энергии (D)
- Способности: щит (Q), ярость (W), лечение (E)
- Комбо-приёмы: лёгкий+лёгкий+тяжёлый = ТРОЙНОЙ УДАР, лёгкий×3+СПЕЦ = СИГМА-ФИНАЛ, тяжёлый+тяжёлый = ДВОЙНОЙ МОЛОТ
- Визуал: тряска экрана, вспышки, летящие цифры урона, баффы на аватарах
- Победа: ДэнКоины + XP + рубли

### Трейд-система
Три монеты — ДэнКоин, РафКоин, ТиКоин. Курс = синусоида + случайное блуждание, обновление 2 раза в секунду.
Canvas-график, портфель со средней ценой, история сделок. Торговля идёт за рубли.

### Промокоды (в Настройках)
`DANYA2026`, `SIGMA`, `GOLDEN`, `VENOM`, `KOMBAT`, `NIGHTDANYA` — каждый активируется один раз.

### Настройки
Сброс прогресса (с подтверждением), переход к ящикам, имя игрока, оптимизация (отключение анимаций),
звук и громкость, быстрые переходы, статистика, экран «Создатели».

## 📦 Деплой на GitHub Pages

    npm run build

В `vite.config.ts` уже стоит `base: './'`, поэтому ассеты грузятся из любой подпапки.

### Вариант 1 — через gh CLI

    git init
    git add -A
    git commit -m "Даня Комбат"
    gh repo create danya-combat --public --source=. --push
    npx gh-pages -d dist
    gh api repos/{owner}/danya-combat/pages -X POST -f build_type=legacy -f source='{"branch":"gh-pages","path":"/"}'

Сайт: `https://{твой-ник}.github.io/danya-combat/`

### Вариант 2 — без gh CLI

1. Запушь репозиторий на GitHub.
2. Выполни `npx gh-pages -d dist` (создаст ветку `gh-pages` и запушит `dist/`).
3. Settings → Pages → Source: `gh-pages` / `(root)`.

Готово.

## 🗂 Структура

    src/
      App.tsx                 # каркас + навигация
      main.tsx                # точка входа
      styles.css              # вся стилизация и анимации
      game/
        data.ts               # скины, улучшения, ящики, промокоды
        state.tsx             # стор игры, формулы, сохранение в localStorage
        audio.ts              # Web Audio API: тона, ноты, эффекты
        format.ts             # форматирование чисел (К/М/Б/Т...) и утилиты
      components/
        ClickerScreen.tsx     # главный экран
        ShopScreen.tsx        # магазин
        BoxesScreen.tsx       # ящики
        EventScreen.tsx       # пассивный фарм с музыкой
        PvpScreen.tsx         # арена
        TradeScreen.tsx       # трейд
        SettingsScreen.tsx    # настройки и промокоды
        CreatorsScreen.tsx    # титры
        DanyaAvatar.tsx       # векторный Даня (все скины)
        Toasts.tsx            # всплывающие уведомления
    public/
      favicon.svg
    index.html
    vite.config.ts

Прогресс сохраняется в `localStorage` каждые 3 секунды и при закрытии вкладки.
Есть оффлайн-доход (до 8 часов).
